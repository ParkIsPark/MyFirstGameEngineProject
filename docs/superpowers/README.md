# Historical design and planning records

The `plans/` and `specs/` directories preserve decisions and proposed implementations at their recorded dates. Old renderer names, numeric settings and format-2 save statements describe historical design stages; they are not current usage instructions. Renderer execution corrections are recorded in [the corrigendum](plans/2026-09-14-hardware-raster-ray-effects-corrigendum.md), preserving the original plan text.

For the implemented hardware raster/secondary ray architecture, format-3 migration, verified call stacks and honest assignment limitations, use [the current rendering guide](../rendering/hardware-raster-ray-effects.md) and [README](../../README.md). For the implemented Actor-only Lua milestone, use [Lua Actor scripting](../scripting/lua-actor-scripting.md).
